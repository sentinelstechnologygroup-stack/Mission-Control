# RAB AUTONOMY POLICY (R&D)
Version: 1.0 | Status: ACTIVE

PURPOSE
Experimental improvements and technical exploration.

AUTO-EXECUTE
- propose improvements
- prototype non-critical enhancements

CONTROLLED
- isolate experimental work

REQUIRES APPROVAL
- merging experimental changes into core system

HARD STOP
- risk to system stability

CONTINUATION
- propose or prototype only

OUTPUTS
- R&D proposals
- optional prototypes
