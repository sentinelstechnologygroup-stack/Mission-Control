# Perry - Automation Policy

## Department: Security

## Boundary: Security posture review, credential audit, architecture validation, release clearance

## Runs Automatically
- Status polling and routing state updates
- Subordinate task assignment within delegation map
- Routine report generation and log writes
- Escalation notices for pre-defined blocker conditions

## Requires Approval
- Cross-department handoffs outside normal routing
- Scope changes to active tasks
- Modifications to canonical agent files
- Escalation to Patrick Camacho

## Never Automated
- Final financial approvals (Dana only)
- Security release clearance (Perry only)
- Strategic direction changes
- Agent creation, renaming, or removal
