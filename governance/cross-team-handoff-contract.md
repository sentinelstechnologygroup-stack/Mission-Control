# Cross-Team Handoff Contract

Status
- Standing Mission Control doctrine
- Required for executive-to-executive, executive-to-QA, and department-to-Nettie handoffs

Every handoff must include:
- handoff_from
- handoff_to
- date_time
- project_or_job
- what is being handed off
- current status
- what is complete
- what remains
- assumptions
- risks
- blockers
- artifacts and file paths
- immediate next step
- decision needed, if any
- owner after handoff

Rules
- No vague handoff summaries
- No hidden assumptions
- No handoff without an owner
- No handoff without next action
- No cross-department state transfer without shared-ledger visibility when running in a sandboxed job

Weak handoff examples
- "Passing to Dana for review"
- "Needs QA"
- "Mostly done"

Strong handoff standard
A receiving executive or QA lead should be able to act immediately without reconstructing missing context from chat history.
